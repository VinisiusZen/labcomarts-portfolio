# Vinicius Zen - Creative Direction + AI Workflows

Static portfolio prepared for GitHub Pages.

## What is inside

- `index.html` - main portfolio page.
- `styles.css` - visual system and responsive layout.
- `script.js` - scroll progress, reveal states and light pointer depth effects.
- `assets/` - self-contained media copied from local prototypes.

## Publish on GitHub Pages

1. Create a public GitHub repository, for example `vinicius-portfolio`.
2. Upload the contents of this folder, not the parent workspace.
3. In GitHub, go to `Settings > Pages`.
4. Choose `Deploy from a branch`.
5. Select branch `main` and folder `/root`.
6. Save.

The site will be available at:

`https://YOUR_USER.github.io/vinicius-portfolio/`

## Wix usage

After publishing, add it to LabComArts as a project card in `folio2026`:

- Title: `AI Creative Workflows`
- Category: `Creative Direction + GenAI`
- Description: `A portfolio case about turning briefs into AI-assisted storytelling, motion prototypes and Creative Ops systems.`
